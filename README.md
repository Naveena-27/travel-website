# Travel Website

A responsive travel landing page built with HTML, CSS and vanilla JavaScript.

## Features

- Sticky header that changes style when you scroll
- Mobile-friendly hamburger menu with a slide-in navigation panel
- Full-screen hero section with a call-to-action button
- Service categories: ship cruises, food tours, summer rest and mountain tours
- Tour package cards with prices and star ratings
- Popular destinations gallery with hover effects
- Newsletter signup form (front-end only)
- Responsive layout for desktop, tablet and mobile

## Built with

- HTML5
- CSS3 (Flexbox, Grid, media queries, CSS variables)
- JavaScript (vanilla, no frameworks)
- [Boxicons](https://boxicons.com/) for icons
- [Google Fonts](https://fonts.google.com/) (Poppins and Paytone One)

## Run it locally

1. Download or clone this repository:
   ```
   git clone https://github.com/Naveena-27/travel-website.git
   ```
2. Open the folder and double-click `index.html`, or open it in your browser.

No installation or build step is needed.

## What I learned

- Building a responsive layout with CSS Grid and Flexbox
- Creating a sticky navbar and a mobile menu with JavaScript
- Using CSS variables to keep colors and font sizes consistent
- Structuring a multi-section landing page
